# Standing rules

Recurring lessons. One line each, pointing to the source build-log entry.

- Never put a phrase in the corpus without running `tools/verify.py` against the cited text. (build-log/01-setup, 2026-10-17 pitfall)
- OCR hyphenated line breaks and spaces before punctuation defeat verbatim checks; shorten the quote to a clean span rather than editing it. (build-log/01-setup, batch 16/18)
- Never guess a locator (verse/chapter) from memory or OCR page numbers; compute it from the text or omit it. (build-log/01-setup, batch 13)
- Check each Gutenberg id's Translator/year before use; ids can be pre-19th-c. editions. (build-log/01-setup, 2026-10-17 pitfall)
